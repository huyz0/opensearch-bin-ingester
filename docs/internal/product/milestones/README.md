# Milestone plans

One directory per milestone, each containing `SPEC.md` written with the
[`spec`](../../../../.agents/skills/spec/SKILL.md) skill before any code.

⚠️ A milestone plan is a **plan**, not a decomposition. The decomposition lives
in [`backlog.md`](../backlog.md) and only for the current milestone — tasks
written three milestones ahead are wrong by the time they are reached.
